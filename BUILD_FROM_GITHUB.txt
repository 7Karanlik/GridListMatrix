1. Upload/commit this project to the repository root.
2. GitHub -> Actions -> Build GridListMatrix -> Run workflow.
3. Open the completed run and download artifact: GridListMatrix-pbiviz.
4. The artifact contains the .pbiviz file.
5. Import the .pbiviz into Power BI Desktop.

The visual implements a real render-time switch:
Matrix Header -> Show Column Header
OFF = no header <tr> elements are created at all.
This is not a white-text workaround.
